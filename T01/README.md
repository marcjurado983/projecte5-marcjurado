# Objectiu de la T01

https://docs.google.com/document/d/1w-XdVpy-1ckS4ehC_UhCLyHTkspzQW91_VqkDSYUKPQ/edit?usp=sharing

L’objectiu d’aquesta tasca **no és redactar un document teòric** ni lliurar un únic Google Docs “ben escrit amb ajuda de la IA”.  

L’objectiu és preparar tota la documentació i els materials necessaris **com si realment haguéssiu d’obrir l’empresa al món real**.

Heu de treballar com ho faria un equip fundador d’una startup IT B2B abans d’aixecar la persiana:

- pensar l’empresa,
- dissenyar-la,
- planificar-la,
- i deixar-la tècnicament i operativament preparada.

Això implica generar **evidències reals**, no només text.

---

## Durant aquesta tasca, s’espera que:

### 📄 Construïu documents tècnics reals
No només documents descriptius:

- plànols,
- esquemes de xarxa,
- pressupostos detallats,
- arquitectures.

### 🎨 Prototipeu
Creació de:

- maquetes web amb Figma,
- estructura web amb Octopus,
- visuals 2D amb IA,
- disseny 3D del local amb Tinkercad o equivalent.

### ⚙️ Implementeu i simuleu
Treballant amb:

- xarxes amb les eines de l’aula,
- configuracions bàsiques,
- serveis cloud justificats.

### 📊 Gestioneu números reals
Mitjançant:

- Excel amb costos,
- programari,
- serveis cloud,
- viabilitat econòmica.

### 🤖 Integreu IA amb criteri
La IA no ha de substituir el treball, sinó actuar com a:

- accelerador,
- eina de contrast,
- suport de millora dels materials.

---

# Objectiu final

Quan presenteu el projecte, **no ha de semblar un treball d’aula**, sinó el dossier real d’una empresa a punt de començar:

- amb un local definit i visualitzat,
- una infraestructura IT pensada per funcionar,
- una presència digital coherent,
- un model de negoci viable,
- i un conjunt d’evidències que demostrin:
  - domini d’eines,
  - criteri tècnic,
  - i capacitat d’execució.
